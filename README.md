## 这是什么

一个适用于**广软（广州软件学院）学生**的**无广告**课表 App。

登录正方教务系统后自动同步课表，数据全部存在手机本地，之后**断网也能看**。

> 本项目由原 Kotlin / View 版重写迁移而来：功能一比一复刻，另新增**液态玻璃 Dock**。

### 为什么做这个

学校官方的课表查询要开浏览器 → 登录 → 点进菜单 → 看一张挤在一起的表格，手机上体验很差。
这个 App 把课表重排成**按天分组的大卡片**，一眼看清"今天有什么课、在哪个教室、还差多久上课"。

## 功能

### 课表

- **按天分组的大卡片** —— 一天一组，卡片显示课程名 / 时间 / 地点 / 教师
- **周次切换** —— 顶部 `‹ 第 N 周 ›` 翻周；点中间弹出周次选择页
- **日期条** —— 横向 7 天，标出每天有几门课
- **回到本周** —— 一键跳回当前周
- **周次智能过滤** —— 自动识别 `1-9周`、`1-17周(单)` 这类规则
- **当日调课** —— 某天临时换成其他星期的课表 / 设为无课（应对补课、放假）

### 外观自定义

- **三种课程卡片样式** —— 彩色填充 / 白底 + 色条 / 纯白底
- **每门课单独配色** —— 24 色 Material 3 色板 + HSV 取色器，改完立即生效
- **液态玻璃 Dock** —— 真正的 3D 折射 / 色散 / 高光（非普通毛玻璃）
- **Dock 外观调节**（独立二级页）—— 位置、宽度、厚度、圆角、滑块尺寸、文字大小、
  动画时长、阻尼回弹，以及**液态玻璃参数**（白度 / 模糊 / 折射厚度 / 色散），全部实时生效、支持一键恢复默认
- **深色模式** —— 跟随系统
- **触感反馈**（独立二级页）—— 多种震动风格 + 强度 + 分场景开关

### 其他

- **首次使用引导** —— 首次同步后提示设置「本学期第一周星期一」（教务只给相对周次）
- **今天页** —— 今日课程 + 距上课倒计时 + 上课进度（上完自动切下一节）
- **成绩 / 考试查询** —— 教务数据同步
- **检查更新** —— 基于 GitHub Releases
- **账号安全** —— 账密仅用于拉取数据，**完成后立即丢弃，不保存在手机上**

## 安装

### 直接下载

到 [release/](release/) 目录下载 `广软课程表-1.2.0.apk`，传到手机安装。

> ⚠️ 需要在系统设置里允许「安装未知来源应用」。
> ⚠️ 用的是 **debug 签名**（个人自用），未上架应用商店。
> ⚠️ **从旧版本升级请先卸载再安装** —— 版本号已重置为 1.2.0，直接覆盖安装会被系统拦截；
> 卸载会清除本地数据，装好后重新同步一次即可。

### 系统要求

- **Android 8.0（API 26）及以上 · arm64**
- **任意网络环境均可使用** —— 不需要校园内网，也不用挂 VPN
  （App 直连学校对外的教务系统域名，这些服务本身对公网开放）

## 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Flutter 3.x（Dart 3）|
| UI | Material 3 + 自绘 Dock（CustomPainter）+ 液态玻璃渲染 |
| 状态管理 | Riverpod |
| 本地库 | drift（SQLite，后台 isolate）|
| 网络 | dio + CookieJar |
| 最低版本 | Android 8.0（API 26）|

### 架构要点

- **本地库是唯一数据源** —— 所有界面只读本地数据库；同步只是「往库里写」。
  断网、教务挂了都不影响查看已同步的数据。
- **教务解析与 UI 完全解耦** —— 解析器是纯 Dart，不依赖任何 UI 框架。
- **主界面 = PageView 三页 + 悬浮液态玻璃 Dock** —— Dock 为叠层悬浮，不占布局空间。

## 关于数据安全

- 账号密码**只在登录那一刻使用**，建立会话后立即从内存丢弃
- 所有课表数据存在手机本地 SQLite，**不上传任何服务器**
- App 没有自建后端 —— 所有请求直连学校教务系统
