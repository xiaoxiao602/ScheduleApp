## 这是什么

一个适用于**广软（广州软件学院）学生**的**无广告**课表 App。

登录正方教务系统后自动同步课表，数据全部存在手机本地，之后**断网也能看**。

### 为什么做这个

学校官方的课表查询要开浏览器 → 登录 → 点进菜单 → 看一张挤在一起的表格，手机上体验很差。
这个小程序/App 把课表重排成**按天分组的大卡片**，一眼看清"今天有什么课、在哪个教室、还差多久上课"。

---

## 功能

### 课表

- **按天分组的大卡片** —— 不用在网格里找格子，一天一组，卡片显示课程名/时间/地点/教师
- **周次切换** —— 顶部 `‹ 第 N 周 ›` 翻周；点中间弹出周次选择页，直接跳到任意周
- **日期条** —— 横向 7 天，标出每天有几门课，点一下跳转
- **回到本周** —— 一键跳回当前周（在本周时置灰）
- **周次智能过滤** —— 自动识别 `1-9周`、`1-17周(单周)` 这类规则，只在对应周显示

### 外观自定义

- **三种课程卡片样式**（设置 → 课程外观）
  | 样式 | 效果 |
  |---|---|
  | 彩色填充 | 整块课程色 + 白字，颜色醒目 |
  | 白底 + 色条 | 白底 + 左侧粗色条，干净有辨识度 |
  | 纯白底 | 白底无装饰，最简洁 |
- **每门课单独配色** —— 24 色 Material 3 官方色板 + HSV 色轮自定义，改完立即生效
- **深色模式** —— 跟随系统
- **Dock 外观调节**（独立二级页）—— 位置、宽度、厚度、圆角、滑块尺寸、文字大小、动画时长、阻尼回弹，全部可调，支持一键恢复默认
- **触感反馈**（独立二级页）—— 6 种震动风格 + 强度调节 + 分场景开关（Dock / 底部导航 / 按钮）
  > 💡 为什么可调：不同手机的震动马达和系统调校不同，同一设置在不同机型上手感不一样 —— 按自己在意的设备调即可。

### 其他

- **首次使用引导** —— 首次同步后提示设置「本学期第一周星期一」（教务接口只给相对周次，不设这个就算不出当前第几周）
- **当日调课** —— 某一天可临时换成其他星期的课，或设为无课（应对周末补课 / 临时放假）。今日页与周课表同步生效，原课表不受影响
- **检查更新** —— 设置页可手动检查新版本（长按切换「自动检查」开关）
- **切页过渡动画** —— 缩放 + 淡入，150ms
- **今天页** —— 今日课程 + 距下节课倒计时（卡片内显示，上完自动切下一节）+ 上课进度
- **成绩 / 考试查询** —— 教务数据同步
- **头像自定义** —— 从相册选图（自动居中裁成圆形），也可用姓氏首字头像
- **账号安全** —— 账密仅用于拉取数据，**完成后立即丢弃，不保存在手机上**（凭据仅用于建立会话）

## 安装

### 直接下载

到 [release/](release/) 目录下载 `广软课程表-1.0.3.apk`，传到手机安装。

> ⚠️ 需要在系统设置里允许「安装未知来源应用」。
> ⚠️ 用的是 **debug 签名**（个人自用），未上架应用商店。

### 系统要求

- **Android 8.0（API 26）及以上**
- **任意网络环境均可使用** —— 不需要校园内网，也不用挂 VPN
  （已实测：移动数据、家用宽带直接访问教务系统均正常）

> 💡 原理：App 直连学校对外的教务系统域名（`jwxt` / `cas` / `ehall`），
> 这些服务本身对公网开放，所以只要手机能上网就能同步课表。

## 技术栈

| 层 | 技术 |
|---|---|
| 语言 | Kotlin 2.0.21 |
| UI | Android View 体系（XML + Fragment）+ Material 3 Expressive 1.14.0 |
| 本地存储 | Room 2.6.1（唯一持久化数据源） |
| 网络 | OkHttp 4.12 + Jsoup 1.18（教务系统是 HTML/JSON 混合） |
| 图片裁剪 | uCrop 2.2.10（头像自定义） |
| 构建 | AGP 8.7.3 / Gradle 8.13 / JDK 21 / KSP |
| 最低版本 | minSdk 26（Android 8.0）|

### 架构要点

```
UI 层（Fragment / Activity）
    ↓
ViewModel（StateFlow 驱动）
    ↓
Repository（本地优先）
    ↓
Room DB  ←  SyncUseCase  ←  ZhengfangDataClient（教务对接）
```

**核心设计决策**：
- **本地库是唯一数据源** —— 所有界面只读 Room，同步只是往 Room 写。这样断网、教务挂了都不影响使用。
- **主界面用 show/hide 切换 Fragment** —— 避免重建 View 树，但要求每个页面都实现 `onHiddenChanged` 才能在切回时刷新（这是个反复踩的坑）。
- **教务解析与 UI 完全解耦** —— `ZhengfangDataClient` / `ZfScheduleParser` / `WeekCalculator` 等是纯 Kotlin，不依赖任何 Android UI。

## 关于数据安全

- 账号密码**只在登录那一刻使用**，登录成功后只保留会话 Cookie，密码立即从内存丢弃
- 会话 Cookie 用 **Android Keystore + EncryptedSharedPreferences** 加密存储
- 所有课表数据存在手机本地 SQLite，**不上传任何服务器**
- App 没有自建后端 —— 所有请求都是直连学校教务系统

---

## 已知限制

- **只支持正方教务系统**（广软用的这套），其他学校需改解析逻辑
- **同步需要能上网**，但**不需要校园内网**；离线时只看本地已同步的数据
- **节假日不自动识别** —— 放假可用「当日调课 → 无课」手动处理；补课可用「当日调课 → 用某天的课表」处理
- 「第一周星期一」需设置一次（教务接口不返回学期起始日）—— 首次同步后会弹窗引导
