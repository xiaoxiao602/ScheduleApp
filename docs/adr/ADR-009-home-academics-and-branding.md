# ADR-009: 首页学业数据展示 + 校徽取色

## 状态

已接受

## 背景

1. 用户要求「把学业数据放到首页」——此前成绩/考试藏在「设置」的二级入口
2. 用户要求「应用内 UI 从校徽取色，比较好看」

## 决策一：首页学业数据（方案 A）

在「今天」页原有内容下方，新增两张卡片：

```
今天页
├─ 顶部品牌区（校徽 + 广软课表 + 账号按钮）
├─ 深色信息卡（日期 / 第 N 周 / 同步状态）
├─ 今日课程（N 门）
├─ 【新增】最近成绩卡片    —— 显示最近 3 条
├─ 【新增】近期考试卡片    —— 显示最近 3 条
└─ 更新于 xx
```

**空数据处理：整张卡片隐藏。**
理由：刚入学时成绩/考试皆空，显示「暂无成绩」占位会显得功能残缺；
有数据才出现，首页更干净，也不会误导。

**「查看全部」入口**：卡片右上角提供，点击进入原有的二级页面
（`GradeListActivity` / `ExamListActivity`），保留完整列表能力。

## 决策二：校徽取色

从 `校徽.png` 提取得到主色：

| 项 | 值 |
|---|---|
| 校徽主色 | `#083878`（HSL 214°, 88%, 25%）—— 深蓝 |
| 占比 | 37.1%（仅次于白色背景） |

⚠️ 原始色明度仅 25%，直接用作浅色主题主色**对比度不足**。
故保持色相 214° 调亮，得到 M3 色阶：

| 色阶 | 值 | 用途 |
|---|---|---|
| primary_10 | `#021D41` | 深色主题背景 |
| primary_20 | `#04316D` | 深色主题容器 |
| primary_30 | `#064190` | 深色主题表面 |
| **primary_40** | **`#0755BC`** | **浅色主题主色** |
| primary_80 | `#79B0F9` | 深色主题主色 |
| primary_90 | `#AECFFB` | 浅色容器 |
| primary_95 | `#BFD9FC` | 高亮容器 |
| primary_99 | `#D1E4FD` | 背景层 |

浅色与深色主题同时提供，跟随系统。

## 影响

**变容易：**
- 学业数据一眼可见，不必进二级页
- 配色与学校视觉识别一致，品牌感更强

**需要注意：**
- 成绩/考试解析器尚未实现（学生无数据），卡片当前恒为空 → 隐藏
- 首页变长，需保持滚动流畅
