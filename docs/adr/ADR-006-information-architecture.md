# ADR-006: 信息架构 —— 三档导航，首屏「今天」

## 状态

已接受

## 背景

参考竞品（同校/同类课表小程序）的界面后，用户选择其信息架构。

竞品的优点（经评审确认值得借鉴）：
1. **顶部信息卡合一**：日期 + 第 N 周 + 状态/行动按钮合成一张深色卡，一眼看到关键信息
2. **首屏 = 「今天」**：学生 90% 的需求是"今天上什么课"，不是浏览整周网格
3. **按使用频率分档**，而非按数据类型堆砌
4. **学院徽标 + 名称 + 副标题**：有归属感
5. **空状态带计数**（「0 门」）：区分"没课"与"没同步"

竞品不可照抄之处：
- **它是 iOS 界面**（home indicator、iOS 状态栏）。抄控件外观会导致 Android 上"四不像"。
  → **只借鉴信息架构，控件沿用 Material 3 Expressive**
- 竞品无成绩/考试入口（可能藏在二级页）

## 决策

**底部导航三档 + 成绩/考试降为二级页面。**

```
┌─────────────────────────────────────────────┐
│              底部导航（3 档）                 │
├──────────┬──────────┬───────────────────────┤
│  今天     │  周课表   │        设置            │
│ (首屏)    │  网格视图  │  账号 / 同步          │
│          │          │  → 成绩（二级）        │
│          │          │  → 考试（二级）        │
│          │          │  清除数据 / 诊断 / 关于 │
└──────────┴──────────┴───────────────────────┘
```

**首屏「今天」页结构：**
```
┌───────────────────────────────────┐
│ [徽标] 广软课表          [账号图标] │
│        广州软件学院 · 个人课表       │
├───────────────────────────────────┤
│ ╔═══════════════════════════════╗ │
│ ║ 2026年9月18日 周五             ║ │  ← 深色信息卡
│ ║ 第 3 周 · 今天                 ║ │
│ ║ [登录教务系统 →] 或 同步时间     ║ │
│ ╚═══════════════════════════════╝ │
├───────────────────────────────────┤
│ 今日课程                    2 门   │
│ ┌───────────────────────────────┐ │
│ │ 高等数学  08:00  1-2节  A101   │ │
│ │ 大学英语  10:00  3-4节  B203   │ │
│ └───────────────────────────────┘ │
└───────────────────────────────────┘
```

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **A. 3 档（今天/周课表/设置）** | 贴近竞品；首屏最高效；符合 M3 建议(3-5档) | 成绩/考试进入二级，路径变长 | ✅ **用户选定** |
| B. 4 档（今天/课表/成绩/考试） | 成绩考试一级可达 | 「我的」无处安放；档位偏多 | ❌ |
| C. 5 档 | 全部一级 | 5 档是 M3 上限，底栏拥挤；低频功能占位置 | ❌ |

**取舍理由**：查成绩是**低频**（一学期几次），看今天是**高频**（每天）。
按频率分档优于按数据类型分档。

## 影响

**变容易：**
- 首屏直达最高频需求，打开 App 0 次点击看到今日课程
- 顶部信息卡把「第几周」这个课表核心信息前置
- 空状态带计数，用户能区分"今天没课"与"没同步数据"

**变难 / 需注意：**
- **成绩/考试需新增二级页面容器**（可从「设置」跳转的 Activity 或嵌套 Fragment）
- 原有的 `GradeFragment`/`ExamFragment` 需要新的宿主
- 「我的」不再是一级入口，其功能（登录/清除/诊断）要整合进「设置」

**保留不动：**
- Material 3 Expressive 主题（不抄 iOS 外观）
- 本地优先架构（ADR-005）
- 周课表网格实现（移动到第二档）
